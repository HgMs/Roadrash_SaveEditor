# 使用说明

> 适用：Road Rash（暴力摩托）1996 PC 中文版 / 英文原版，存档 `*.RRS`

---

## 一、能改什么

| 能改 | 说明 |
|---|---|
| **金钱** | 0 ~ 99,999,999，游戏里买车、修车都够用 |
| **当前摩托车** | 15 台任选，选完游戏里就是这辆车 |
| **已通关的关卡** | 5 条赛道，点亮即视为已通关，可以只补某一条 |
| **一键变强** | 满金钱 + 全关卡 + 顶级车（DMG M10），三秒搞定 |

**不提供修改**：车手、AI 数据、比赛名次等。这些字段和文件名、录像数据绑定，乱改容易出现「车手对不上档」的问题，所以故意没开放。

---

## 二、怎么用（三步）

1. **双击** `暴力摩托存档修改器.exe`，等 2~5 秒会弹出一个黑色窗口（用系统自带的 Edge 内核渲染，不需要另外装东西）。
2. 右上角显示的就是**当前存档**。点它可以在你的存档之间切换：
   - 列表里按「最近玩过」排序，第一条会默认打开；
   - 想选别的文件，点列表最下面的「打开其他文件…」。
3. 改完点右下角 **「保存到游戏」**。看到「✓ 已保存到 戴维.RRS，原文件已备份」就成功了。

然后回游戏 → **载入游戏** → 选这个存档，金钱、车、关卡就都是新的了。

> 改完不点保存是**不会写入**的；工具栏会显示「有改动未保存」。

---

## 三、存档在哪

```
C:\Games\Roadrash\Save\戴维.RRS
C:\Games\Roadrash\Save\汤姆.RRS
```

- 文件名就是你的**车手名字**，游戏里存盘时起什么名，这里就叫什么。
- 游戏根目录偶尔还有一个 `962.RRS`，那是安装包自带的示例档。
- 游戏装在别的盘也没关系：工具会通过注册表 + 常见目录自动找；找不到时点「打开其他文件…」手动选一次，下次会记住。

## 五、为什么不会把存档改坏

工具在后台做了四件事，界面上看不到：

1. **自动备份**：每次保存前，先把原文件复制成
   `戴维.RRS.bak_20261116_135001`（同目录，最多保留最近 5 份，更早的自动清理）。
2. **先写临时文件再覆盖**：只有新文件完整写好了才替换原文件；中途出错原文件一个字节都不动。
3. **重算校验和**：存档开头 4 个字节是校验和，改了内容不重算，游戏和 Windows 属性页都会把它当成「伪造的游戏进度文件」直接拒读。工具每次保存都会自动重算。
4. **游戏运行检测**：检测到 `Roadrash.exe` 正在跑就拒绝保存，并提示「先把游戏关掉」——否则游戏退出时会用内存里的旧数据把你的修改覆盖掉。

---

## 六、改坏了怎么恢复

1. 打开 `C:\Games\Roadrash\Save\`，按修改时间排序；
2. 找到 `戴维.RRS.bak_2026xxxx_xxxxxx`；
3. 把它的名字改回 `戴维.RRS`（先删掉/改名现在的 `戴维.RRS`）；
4. 回游戏读档即可。

> 备份就是普通文件，改名就能用，不需要工具。

## 七、常见问题

**双击后半天没窗口？**
第一次启动要拉起 Edge 内核，慢的话 3~5 秒；超过 10 秒还没有窗口，看看任务栏有没有被挡住的「暴力摩托 · 存档修改器」。

**提示「这个文件不是暴力摩托的存档」**
只认 **160 字节**的 `.RRS`。选错文件（`.rsc`、`.bob` 或别的游戏存档）会这样提示。

**提示「游戏正开着，先把游戏关掉再保存」**
退出游戏（不是最小化）再点保存。

**保存成功，但进游戏数值没变？**
游戏不会自动读盘，要在主菜单 **载入游戏** 里重新读取这个存档。

**杀毒软件报毒？**
这是一个自编译的小程序（约 240 KB），行为是「起一个只监听 127.0.0.1 的小服务 + 调用系统 Edge 显示界面 + 读写你选中的存档文件」。
源码在 `src/Launcher.cs`，可以自己编译：见 README。

**能改 Steam 30 周年版吗？**
只要存档还是 160 字节、后缀 `.RRS`，结构就一致，可以改。

## 八、原理（想了解再看）

存档固定 160 字节，本工具只改其中 3 个字节 + 重算开头 4 个字节：

| 偏移 | 内容 |
|---|---|
| `0x00` | 校验和 |
| `0x0B` | 已通关关卡位图 ← **改这里** |
| `0x0C` | 摩托车编号 ← **改这里** |
| `0x10` | 金钱（int32）← **改这里** |

完整结构、校验和算法见 [save-format.md](save-format.md)。
